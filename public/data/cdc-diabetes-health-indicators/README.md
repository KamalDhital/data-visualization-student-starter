# CDC Diabetes Health Indicators Dataset

## Dataset Source

Downloaded from:
https://archive.ics.uci.edu/dataset/891/cdc+diabetes+health+indicators

## Description

The CDC Diabetes Health Indicators Dataset contains healthcare statistics and lifestyle survey information collected through the Behavioral Risk Factor Surveillance System (BRFSS).

Each row represents an individual and includes health factors such as:

- Diabetes status
- Blood pressure
- Cholesterol
- BMI
- Smoking habits
- Physical activity
- Age
- Education
- Income
